# Background Daemon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move polling, tracking, state, notifications, and GitHub actions into a long-running daemon; make the TUI a socket client with auto-start and start/stop.

**Architecture:** Three stages, each shippable. (1) Extract a Textual-free `Monitor` service behind a `Backend` interface and run it in-process — no user-visible change. (2) Add the socket protocol, `DaemonServer`, `RemoteBackend`, and daemon lifecycle/CLI. (3) Switch the CLI's TUI to `RemoteBackend`, add backend status, `S` start/stop, disconnect and version handling.

**Tech Stack:** Python 3.11+, textual, httpx, stdlib (`asyncio` Unix sockets, `json`, `fcntl`, `argparse`, `logging`, `importlib.metadata`), unittest.

**Spec:** `docs/superpowers/specs/2026-09-17-daemon-design.md`

## Global Constraints

- All imports at module level. unittest only. No new dependencies.
- The daemon is the only writer of `config.toml` / `state.json`.
- Socket/lock/log live in `$XDG_STATE_HOME/pr-mon/` (`daemon.sock`, `daemon.lock`, `daemon.log`).
- JSON lines, UTF-8; request `{"id","op","args"}`, response `{"id","ok","result"|"error"}`, event `{"event","data"}`.
- Version = `importlib.metadata.version("pr-mon")`.
- Existing behavior (tree, badges, first-load gate, notification rules, actions) must not change; the existing test suite is the regression net and is migrated, not deleted.
- Every stage ends with `make lint test` green and a commit.

### Task 3: `Backend` interface and `Monitor` service

**Files:** Create `src/pr_mon/backend.py`, `src/pr_mon/service.py`, `tests/test_service.py`.

**Produces (backend.py):**
- `class BackendError(Exception)`
- `@dataclass BackendStatus(connected: bool = True, pid: int | None = None, version: str = "", notifier: str | None = None, last_update: str | None = None, rate_limited_until: str | None = None, warnings: list[str] = [])`
- `@dataclass(frozen=True) BackendEvent(kind: str, name: str | None = None, alerted: bool = False, message: str = "", severity: str = "information")`
- `class Backend(Protocol)` with the read attributes and async commands from the spec, plus `add_listener(callback: Callable[[BackendEvent], None])`.

**Produces (service.py):** `class Monitor` implementing `Backend`:
- `Monitor(client, config_path, state_path, notifier, version="")`
- `async start()` — load config/state (warnings into `status.warnings`), start the poll loop task.
- `async stop()` — cancel poll loop, retry timers and notification tasks; save state.
- `async poll_once()` — refresh every repo concurrently (used by the loop and by tests).
- `async refresh_repo(name, attempt=0)` — fetch, apply, rate-limit pause, CHECKING retries via `asyncio.get_running_loop().call_later` → task.
- Commands per spec. `perform` emits toasts exactly like today's `PrMonApp.perform`, then refreshes the repo. `send_test` emits "Test X notification sent" / "Nothing to send…" toasts.
- `apply(name, repo)` — moves today's logic: changes → notifications (first-load gate, per-repo settings) → tracker.update → `repo` event with `alerted`.
- Notification failures → `toast` events with severity `warning`.

- [ ] Port the logic tests from `tests/test_app.py` `NotificationDispatchTest` into `tests/test_service.py` against `Monitor` directly (FakeClient, patched `deliver`), plus: add/remove repo (duplicate, not found, canonical name, settings removal, state forget), rate-limit pause skips `poll_once`, CHECKING schedules up to 3 retries, errors keep last data, perform toasts (merge, delete failure warning, merge failure error, auto-merge on/off, update), mark_seen emits `seen` and persists, set_collapsed persists.
- [ ] Implement `backend.py` and `service.py`. Commit.

### Task 7: `RemoteBackend`

**Files:** Create `src/pr_mon/remote.py`, `tests/test_remote.py`.

**Produces:** `RemoteBackend(socket_path)` implementing `Backend`: `async connect()` (hello + snapshot, raises `BackendUnavailable` if no socket), request/response via futures keyed by id, reader task applying events to the mirror before notifying listeners, `disconnected` event on EOF, optimistic `mark_seen`, `async close()`.

- [ ] Tests against a real `DaemonServer` + `Monitor` (FakeClient): mirror matches monitor after snapshot; `repo` events update mirror; commands round-trip; errors raise `BackendError`; server close → `disconnected` and `status.connected is False`; commands while disconnected raise `BackendError("backend stopped")`. Implement. Commit.

### Task 8: Daemon lifecycle

**Files:** Create `src/pr_mon/daemon.py`, `tests/test_daemon.py`, `tests/daemon_harness.py`.

**Produces:**
- `DaemonPaths(state_dir)` with `socket`, `lock`, `log`
- `async run_daemon(paths, client, config_path, state_path, notifier)` — take lock (else `AlreadyRunning(pid)`), remove stale socket, logging, SIGTERM/SIGINT → shutdown, start monitor + server, wait for shutdown, clean up.
- `spawn_daemon(paths) -> int` — `subprocess.Popen([sys.executable, "-m", "pr_mon", "daemon"], start_new_session=True, stdin=DEVNULL, stdout/stderr → log)`; wait up to 5 s for the socket.
- `daemon_status(paths) -> int | None` — pid from lock file if the lock is held.
- `stop_daemon(paths, timeout=5) -> bool` — `shutdown` op, wait for lock release, SIGTERM fallback.

- [ ] Tests: `tests/daemon_harness.py` runs `run_daemon` with a FakeClient in a subprocess; status running/stopped; second daemon → AlreadyRunning; stale socket removed; `stop_daemon` cleans socket and lock; SIGTERM cleans up and saves state. Implement. Commit.

## Stage 3 — TUI as a client

### Task 10: Connect, auto-start, version check

**Files:** Modify `src/pr_mon/cli.py`, `src/pr_mon/app.py`; Tests `tests/test_app_remote.py`.

- `cli` TUI path: `RemoteBackend.connect()`; on `BackendUnavailable` → `spawn_daemon()` → connect; failure → exit with last 10 log lines.
- Version mismatch → modal "Backend is version X, TUI is Y. Restart backend?" → yes: `stop_daemon` + spawn + reconnect; no: quit.
- `PrMonApp(backend, owns_backend=False)`; on unmount close the connection only.
- [ ] End-to-end tests (real server + Monitor with FakeClient in the test loop): TUI renders snapshot; `A`/`D`/merge/`N` save go through the socket; closing TUI leaves daemon running; toasts arrive. Commit.
